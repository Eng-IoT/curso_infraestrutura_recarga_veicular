# Formação Profissional — Projetos de Infraestrutura de Recarga Veicular

MVP funcional V1.

## O que já está implementado
- 20 microaulas / 80 horas
- progresso local no dispositivo (localStorage)
- conteúdo técnico inicial em todas as microaulas
- atividades e quizzes
- botão no final da aula: Aula anterior / Concluir aula / Próxima aula
- barra inferior persistente durante as aulas
- Projeto Final com checklist
- Certificado liberado após conclusão
- SAVE Engenharia liberado após 20 aulas + Projeto Final
- link profissional: https://saevengenharia.vercel.app/
- identidade visual Joelson Mendes
- PWA básica/offline

## Executar localmente
Na pasta do projeto:
python -m http.server 8080

Acesse:
http://localhost:8080

## Publicar na Vercel
Como é um site estático, pode ser publicado diretamente como Static Site ou dentro de um repositório GitHub conectado à Vercel.
